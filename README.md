# smart_bird_id_orchestrator

Coordination repo for the Smart Bird ID multi-agent relay (iOS, Android, cloud, BirdMedia).

- `AGENTS.md` — the orchestrator's role, workflow and standing rules (Codex reads this automatically).
- `HANDOFF.md` — current state, counters, open decisions, release to-dos.

Request files, owner specs, translations and proofs still live in each app repo's `_orchestrator/` folder.
